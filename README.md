# Steam-Train-Info
Information pamphlet test

## Overview:

This project is a minimalistic website created for the purpose of sharing some information about a steam locomotive. I volunteer as a Coach Controller on a Steam Train where we do rides for passengers to experience the feeling of the old trains. This website is mainly used to provide information for passengers that wants to share some of the information about the locomotive with family or friends that are not on the train while it is riding.

## Technology used:

- HTML
- CSS
- JavaScript

## How it works:

Click on the category that looks interesting to expand it and reveal the information within that category.
